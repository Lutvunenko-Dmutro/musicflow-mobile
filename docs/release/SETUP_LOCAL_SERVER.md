# Розгортання локального сервера оновлень (OTA)

Цей документ описує, як запустити локальний Python-сервер для бездротової передачі APK-файлів (Over-The-Air) на телефон розробника та тестувальників у локальній Wi-Fi мережі.

## 1. Вимоги

- **Python 3.8+** (Встановлено та додано в PATH).
- Смартфон та ПК знаходяться в **одній Wi-Fi мережі**.
- Скомпільований APK файл.

## 2. Встановлення залежностей

Локальний сервер `server/publish_release.py` побудований на стандартній бібліотеці Python (`http.server`), тому не потребує встановлення додаткових пакетів через `pip` для базової роботи. 

Однак, для розрахунку SHA-256 та роботи з GitHub API (якщо планується публікація), переконайтеся, що ви маєте доступ до командного рядка.

## 3. Запуск сервера

1. Відкрийте термінал у кореневій директорії проекту.
2. Запустіть скрипт публікації в режимі `local`:

```bash
python server/publish_release.py -m local -c "Локальний тестовий білд"
```

Скрипт автоматично:
- Скомпілює поточний код у `release` APK.
- Скопіює APK в `server/data/updates/`.
- Оновить `version.json` (пропише новий номер версії, розмір файлу та порахує SHA-256).
- Запустить HTTP-сервер на порту `8080`.

Ви побачите в терміналі адресу сервера, наприклад:
`Server running on http://192.168.1.100:8080`

## 4. Налаштування телефону (Client Setup)

Щоб додаток на телефоні знав, куди звертатися за оновленням:

1. Відкрийте **MusicFlow Mobile** на телефоні.
2. Перейдіть в **Налаштування** -> **Канал оновлень** (Update Channel).
3. Змініть канал на `Custom Server` (або `Developer`).
4. Введіть IP-адресу вашого ПК, яку показав сервер (наприклад: `http://192.168.1.100:8080`).
5. Збережіть налаштування.

Тепер при натисканні "Перевірити оновлення" додаток звертатиметься до вашого локального ПК.

## 5. Web Dashboard

Для перегляду статистики, звітів про збої (якщо включена телеметрія) та статусу поточного APK:
Відкрийте в браузері на ПК або телефоні:
`http://localhost:8080/dashboard` (або IP вашого ПК `http://192.168.1.x:8080/dashboard`).
