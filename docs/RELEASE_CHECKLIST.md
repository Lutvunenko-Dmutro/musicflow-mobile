# Чек-лист випуску релізу (RELEASE_CHECKLIST.md)

Цей чек-лист є обов'язковим інженерним протоколом перед публікацією будь-якого оновлення **MusicFlow Mobile**. Жоден реліз не повинен виходити без проходження всіх пунктів.

---

## 📋 Фаза 1: Автоматичний Pre-Flight (100% Zero-Tolerance)

- [ ] **1.1 Статичний аналіз:** `flutter analyze` повертає `No issues found!` (0 помилок, 0 попереджень).
- [ ] **1.2 Набір тестів:** Усі 55+ тестів проходять успішно (`flutter test`).
- [ ] **1.3 Архітектурний ліміт:** `test/architecture/file_length_test.dart` підтверджує, що жоден файл у `lib/` та `test/` не перевищує **200 рядків**.
- [ ] **1.4 Модульність сервера:** Усі файли в `server/` мають менше **200 рядків**.

---

## 📱 Фаза 2: Ручний Smoke-тест на пристрої / емуляторі

- [ ] **2.1 Холодний запуск (Cold Start):** Додаток запускається менш ніж за 1.5 секунди без білих екранів чи зависань.
- [ ] **2.2 Локальне відтворення:** Запуск локального треку (MP3/FLAC) відбувається миттєво (< 300 мс).
- [ ] **2.3 Стрімінг YouTube:** Трек успішно підтягується, обкладинка та синхронізовані рядки караоке рендеряться без збоїв.
- [ ] **2.4 Спектральний аналізатор:** Смужки візуалізатора стрибають плавно і на весь розмах як на міні-барі, так і на головному плеєрі.
- [ ] **2.5 Фоновий режим та Lockscreen:** При блокуванні екрана музика продовжує грати, системні кнопки паузи/перемотування працюють бездоганно.
- [ ] **2.6 Відключення навушників (Becoming Noisy):** При витягуванні навушників відтворення плавно зупиняється (`smoothPause`), динамік телефону не кричить.

---

## 🔒 Фаза 3: Безпека, Підпис та Цілісність

- [ ] **3.1 Цифровий підпис:** Релізний білд підписано офіційним ключем `MusicFlow` (`release.keystore`), що забезпечує оновлення поверх встановленої версії без конфліктів.
- [ ] **3.2 Контрольна сума SHA-256:** У `version.json` згенеровано актуальний хеш SHA-256, який збігається з файлом `app-release.apk`.
- [ ] **3.3 Валідація OTA:** Додаток успішно верифікує SHA-256 під час завантаження перед запуском системного встановлювача.
