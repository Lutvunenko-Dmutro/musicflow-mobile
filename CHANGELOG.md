# Журнал змін (CHANGELOG.md)

Усі ключові покращення, оновлення та виправлення проєкту **MusicFlow Mobile** фіксуються в цьому документі в хронологічному порядку за датами випуску.

---

## 📅 11 жовтня 2026
### 🛠️ Архітектура, OTA та Інфраструктура
- **Канали оновлень:** Реалізовано перемикання між Release (стабільний канал через GitHub Releases API) та Debug (локальний сервер розробки) з миттєвою синхронізацією налаштувань.
- **Очищення маніфесту оновлень:** Покращено парсинг Changelog у діалозі оновлення — видалено службові маркери форматування, хеші SHA-256 та технічні символи для чистого відображення користувачу.
- **Структурування документації:** Усі технічні документи згруповано за категоріями (`docs/architecture/`, `docs/planning/`, `docs/release/`, `docs/quality/`).
- **Контроль цілісності:** Впроваджено автоматичний тест `repo_integrity_test.dart` для перевірки синтаксису GitHub Actions workflows та валідації всіх локальних посилань у Markdown документах.

---

## 📅 7 жовтня 2026
### 🔒 Безпека та Інфраструктура (Hardening)
- **SHA-256 Checksum Validation:** Додано потокову перевірку хешу SHA-256 при завантаженні оновлень APK (`UpdateService.downloadApk`). Якщо хеш не збігається з маніфестом, файл негайно знищується для захисту від підміни або пошкодження.
- **CI/CD Automation:** Створено повноцінний хмарний пайплайн `.github/workflows/ci.yml` із перевіркою `flutter analyze`, `flutter test` та компіляцією `flutter build apk --release`.
- **Серверна безпека:** Додано Rate Limiting (захист від перевантаження запитами) та автоматичну санітизацію персональних даних і шляхів файлів користувача зі звітів телеметрії у `server/server.py`.
- **Матриця надійності:** Створено `docs/release/COMPATIBILITY_AND_ROLLBACK.md` із розмежуванням рівнів Core/Platform/Experimental та планом відкату.

### 🐛 Виправлення
- **Візуалізатор спектра:** Виправлено колапс полотна `CustomPaint` через повернення обов'язкового `SizedBox.expand` у `audio_visualizer.dart` (смужки більше не схлопуються в одну крапку).
- **Синхронізація 1:1:** Уніфіковано параметри ширини й кількості смуг між міні-баром на головному екрані та повнорозмірним плеєром.
- **Апаратний захист:** У `visualizer_bars_painter.dart` додано перевірку нульових розмірів для запобігання артефактів під час переходу між екранами.

### 🎨 Естетика
- **Flowing Ambient Glow:** Зменшено розмиття до шовкових 28px та додано дві неонові орбітальні сфери світла, що пульсують за синусоїдою кожні 4 секунди.

## 📅 6 жовтня 2026
### 🚀 Новий функціонал та UX
- **10-смуговий Еквалайзер:** Додано підтримку 12 пресетів (Rock, Pop, Bass Boost тощо) із прямим мапуванням частот (31 Гц – 16 кГц) на нативний аудіочип смартфона.
- **GitHub OTA Updates:** Автономне отримання релізів прямо через GitHub Releases API без необхідності запуску локального ПК-сервера.
- **Flowing Light:** Живе синусоїдальне дихання та динамічний плавний перелив фону плеєра на GPU.
- **Cover Sheen:** Оптичний тактильний блік на обкладинці, що реагує на горизонтальний жест свайпу.
- **Apple Music Synced Lyrics:** Пружинний автоскрол активного рядка караоке та миттєве перемотування треку за тапом на текст.
- **Alphabet Index Bar:** Швидкий скролер медіатеки (#, A-Z, А-Я) з плаваючою бульбашкою та тактильним вібро-клацанням (автоматичне приховування при сортуванні за датою додавання).

### 🐛 Виправлення та калібрування
- Синхронізація спектрального аналізатора між міні-баром та екраном плеєра.
- Додано захист від фонових перемалювань під час відкриття нових екранів.
- Закріплено живе прев'ю візуалізатора вгорі екрана налаштувань (60 смуг прев'ю для повної відповідності плеєру).
