## Можливості додатку

| Функція | Опис | Статус |
|---|---|:---:|
| 📂 **Локальна бібліотека** | Сканування та відтворення MP3/M4A/FLAC, кешування ID3 тегів у SQLite для миттєвого старту | ✅ |
| 🌐 **YouTube стрімінг** | Пошук, фонове відтворення, автоматичний refresh потоків при закінченні терміну дії URL (403 retry) | ✅ |
| 🔄 **Мережева надійність** | Exponential Backoff (3 спроби з наростаючою затримкою) на всі запити до YouTube | ✅ |
| ⬇️ **Завантаження музики** | Викачування аудіо, автоматичне обрізання обкладинки 1:1, запис ID3 тегів та сканування в MediaStore | ✅ |
| 📜 **Синхронізовані тексти** | Підтримка LRC, LRCLIB API, парсинг та калібрування таймінгів авто-субтитрів YouTube | ✅ |
| 📊 **FFT-візуалізатор** | 60-смуговий спектрограф із Software (fftea) та Hardware ядрами, згладжуванням та +3dB headroom | ✅ |
| 🎚️ **Native Еквалайзер** | Android-native через `AudioPipeline`, синхронізація на обидва плеєри, пресети та Bass Boost | ✅ |
| 🔀 **Справжній Crossfade** | Плавний перехід між треками без пауз завдяки архітектурі на двох `AudioPlayer` | ✅ |
| 🧹 **Керування пам'яттю** | Детальна статистика зайнятої пам'яті (обкладинки, LRC, SQLite, історія) та безпечне очищення | ✅ |
| 🛡️ **Захист від race conditions** | Безпечне швидке перемикання треків (`_playRequestId`), відсутність помилок переривання | ✅ |
| 🧪 **Автоматичні тести** | 14 автоматичних unit-тестів: моделі, expire-таймінги, FFT-алгоритми та архітектурний ліміт розміру файлів (< 200 рядків) | ✅ |

## Стек технологій

| Компонент | Технологія / Бібліотека |
|---|---|
| **Фреймворк** | Flutter 3.x (Material 3, Impeller) |
| **Управління станом** | `provider` (ChangeNotifier + Mixins) |
| **Впровадження залежностей** | `get_it` (Service Locator) |
| **Аудіо ядро** | `just_audio` + `audio_service` + `audio_session` |
| **YouTube інтеграція** | `youtube_explode_dart` (кастомний fork із захистом від 403) |
| **Локальне сховище** | `sqflite` (SQLite v3) + `shared_preferences` |
| **Цифрова обробка сигналу** | `fftea` (ШПФ) + Android Native `Visualizer` |
| **Метадані та теги** | `audiotags` (Rust FFI engine) |
| **Мережа та зображення** | `http`, `cached_network_image`, `image` |
| **Локалізація** | `easy_localization` (Українська / Англійська) |

## Архітектура проекту

Додаток використовує модульну архітектуру:
- **`AudioProvider`** агрегує кілька спеціалізованих міксинів (черга, контролери відтворення, плавність кросфейду, налаштування, тексти, відновлення стрімів).
- **`Native Handlers`** (Kotlin) винесені в окремі класи: `VisualizerHandler` та `MediaScannerHandler`, зберігаючи `MainActivity.kt` компактним і чистим.
- **`AppLogger`** забезпечує єдине структуроване кольорове логування з категоріями (`AUDIO`, `DOWNLOAD`, `EQ`, `YOUTUBE`, `FFT`, `SETTINGS`).
- **Модульність та ліміт файлів:** Усі файли проекту (`lib/` та `test/`) суворо обмежені довжиною до 200 рядків, що автоматично перевіряється в CI/тестах (`file_length_test.dart`).

│   ├── playback_controls_mixin.dart
│   ├── lyrics_manager_mixin.dart

## Запуск та тестування

### 1. Запуск unit-тестів
```bash
flutter test
```
Запускає повний набір із 14 автоматизованих тестів на стабільність моделей, алгоритмів FFT, парсингу сесій та лімітів довжини файлів (< 200 рядків).

### 2. Перевірка коду лінтером
```bash
flutter analyze
```

### 3. Запуск додатку
```bash
# Debug запуск на підключеному пристрої
flutter run

# Збірка релізного APK
flutter build apk --release
```

> **Системні вимоги:** Android 6.0+ (API 23+) для коректної роботи апаратного FFT-візуалізатора.

## Безпека та сховище

- **Безпека файлів користувача:** Операції очищення кешу та скидання історії ніколи не торкаються і не видаляють власні завантажені або локальні аудіотреки користувача (`.mp3`, `.m4a`, `.flac`).
- **Гранулярне керування кешем:** Вбудована картка `CacheInfoCard` на екрані налаштувань дозволяє незалежно очищати обкладинки, синхронізовані тексти LRC або історію відтворення з підтвердженням у модальному вікні.
- **Динамічні шляхи завантаження:** Підтримка збереження треків у системну папку `Music`, користувацьку директорію або локальне сховище додатку з подальшим авто-індексуванням у `MediaStore`.
- **Кешування дозволів:** Системний дозвіл на використання мікрофона для FFT-візуалізатора запитується один раз і кешується в `SharedPreferences` без надокучливих повторних запитів.
