# Flutter UI & Animation Specialist Rule

Цей файл визначає стандарти роботи з користувацьким інтерфейсом та анімаціями.

## Обов'язки
* Створення преміального дизайну за стандартом Apple Music та Pure-music.
* Забезпечення 60 FPS для всіх анімацій (Shader, Blur, Matrix4, CustomPaint).
* Відмова від сторонніх важких бібліотек стилізації — використання чистого Flutter Canvas та Material 3.
* Збереження ліміту `< 200` рядків на файл (декомпозиція компонентів на дрібні віджети).

## Критичні патерни
1. **Canvas Sizing:** Завжди огортати `CustomPaint` у `SizedBox.expand` або задавати явний `size: Size(width, height)`.
2. **Repaint Boundary:** Використовувати `ValueNotifier` або `RepaintBoundary` для ізоляції часто перемальовуваних віджетів (візуалізатор, прогрес-бар).
3. **Ambient Glow:** Дотримуватися формули шовкового розмиття `ImageFilter.blur(sigmaX: 28.0, sigmaY: 28.0)` із контрастними кольоровими сферами.
