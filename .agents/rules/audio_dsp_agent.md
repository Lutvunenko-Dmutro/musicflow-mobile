# Audio & DSP Specialist Rule

Цей файл визначає стандарти роботи з аудіоядром, цифровою обробкою сигналу та нативними мостами Android.

## Обов'язки
* Підтримка надійного стрімінгу аудіо з YouTube через `youtube_explode_dart`.
* Обробка помилок мережі: обов'язковий Exponential Backoff (3 спроби) та авто-поновлення URL при 403 кодах.
* Синхронізація нативного коду Kotlin (`VisualizerHandler.kt`) з Dart через `EventChannel`.
* Математика ШПФ (`fftea`): логарифмічне шкалювання частот, +3dB headroom, відсів нульових бінів (0 Гц).
* Збереження позиції треку при перемиканнях та зміні джерела відтворення.
