# Release & DevOps Specialist Rule

Цей файл регулює процеси компіляції, версіонування та доставки оновлень (OTA).

## Обов'язки
* Автоматизація збірки виключно через `python server/publish_release.py`.
* Заборонено запускати ручні кроки збірки окремо: усе має виконуватися через єдиний пайплайн із прапорцем `-c "Опис змін"`.
* Автоматичне оновлення `pubspec.yaml`, `version.json`, бінарників `app-release.apk` у сховищі сервера.
* Синхронізація з Git: автоматичний коміт усіх змінних файлів (`git add -A`), створення тегу `vX.Y.Z` та push у GitHub.
* Перевірка цілісності артефактів після завершення компіляції.
